Using it

Point a booklet at this registry and these appear under Add an activity. The renderer fetches this one file — about 1.2KB — and downloads a module only when somebody adds it.

{ "block": "meta", "registries": ["https://benthepsychologist.github.io/booklet/registry.json"] }

Adding one

A module is Markdown with one fenced JSON block — text and config, no code. Open a pull request; see CONTRIBUTING.md. This list carries examples, not advice of any kind.
